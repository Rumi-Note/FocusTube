FocusTube Privacy Policy

Effective date: October 22, 2026

FocusTube is designed to work without collecting personal information.

Information FocusTube processes

FocusTube processes the position and dimensions of the visible YouTube video player locally in the browser so it can place visual overlays correctly. It does not read, record, or store video or audio content.

FocusTube stores only these preferences through Chrome Sync:

  • Whether focus mode is enabled
  • Video overlay opacity
  • Video blur amount
  • Surrounding-page overlay opacity
  • Surrounding-page blur amount
  • Video edge gap

These preferences do not contain browsing history, page content, account information, or other personal information. Chrome Sync is provided by Google and is governed by Google's applicable privacy terms.

Data collection and sharing

FocusTube does not:

  • Operate a developer-controlled server
  • Collect or transmit browsing history or website content
  • Collect personally identifiable information
  • Use analytics, advertising, or tracking technologies
  • Sell, rent, or share user data
  • Use remote code

Data retention and deletion

Preferences remain in Chrome Sync until the user resets them, removes the extension, or deletes synced extension data through their Google Chrome account settings.

Changes to this policy

If FocusTube's data practices change, this policy and the Chrome Web Store privacy disclosures will be updated before the changed version is published.

Contact

For privacy questions, open an issue in the FocusTube support repository.
