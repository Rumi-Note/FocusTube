# FocusTube Chrome Web Store listing

## Recommended listing settings

- Category: Productivity
- Primary language: English
- Additional language: Chinese (Simplified)
- Visibility: Public
- Single purpose: Reduce distractions on YouTube by applying independently adjustable opacity and blur overlays to the current video and the surrounding page.

## English

**Name**

FocusTube – YouTube Focus Mode

**Summary**

Dim and blur the current video and surrounding page separately for distraction-free YouTube viewing.

**Detailed description**

FocusTube helps you stay focused while watching YouTube.

Instead of hiding the whole page with one fixed effect, FocusTube gives you separate controls for the current video and everything around it. Adjust each area until the page feels comfortable and distraction-free.

Features:
- Independently adjust overlay opacity for the current video and surrounding page
- Independently adjust blur for the current video and surrounding page
- Add a configurable gap around the video edge
- Quickly enable, disable, or reset focus mode
- Works with standard videos, theater mode, and Shorts
- Automatically hides overlays in full screen
- Saves settings with Chrome Sync
- English and Simplified Chinese interface

Privacy first:
- No analytics or advertising
- No browsing history collection
- No video or audio recording
- No external server and no remote code

FocusTube is an independent extension and is not affiliated with or endorsed by YouTube or Google.

## 简体中文

**名称**

FocusTube – YouTube 专注模式

**摘要**

分别调节当前视频和页面其他区域的遮罩透明度与模糊度，减少 YouTube 观看干扰。

**详细说明**

FocusTube 帮助你在观看 YouTube 时保持专注。

它不会用一种固定效果覆盖整个页面，而是把当前视频区域与周围页面分开控制。你可以分别调节两块区域，找到舒适、低干扰的观看状态。

主要功能：
- 独立调节当前视频区域的遮罩透明度
- 独立调节页面其他区域的遮罩透明度
- 分别调节两块区域的模糊度
- 自定义视频边缘留白
- 一键启用、关闭或恢复默认设置
- 支持普通视频、影院模式和 Shorts
- 全屏播放时自动隐藏遮罩
- 使用 Chrome Sync 保存设置
- 内置英文和简体中文界面

隐私优先：
- 不含分析或广告
- 不收集浏览历史
- 不录制视频或音频
- 不连接开发者服务器，也不使用远程代码

FocusTube 是独立开发的扩展，与 YouTube 或 Google 不存在隶属或背书关系。

## Permission justifications

**storage**

Stores only the enabled state and five visual preferences (video opacity, video blur, surrounding-page opacity, surrounding-page blur, and edge gap) with Chrome Sync so the user's settings persist.

**activeTab**

Allows the popup to send the user's current visual settings to the active YouTube tab after the user clicks the extension. It is not used to read browsing history.

**Host access to `https://www.youtube.com/*`**

Required to find the visible YouTube player locally and draw the focus overlays around and over it. FocusTube does not send page or video data anywhere.
